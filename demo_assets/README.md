# Demo Assets

This folder contains sample files for hackathon demo.

## Files

| File | Purpose |
|------|---------|
| `sample_tomato_leaf.jpg` | Demo tomato leaf with blight symptoms |
| `sample_wheat_leaf.jpg` | Demo wheat leaf with rust symptoms |
| `sample_audio.wav` | Demo Hindi voice: "मेरे टमाटर में बीमारी है" |

## Usage

Upload these files through the Krishi-Sarthi dashboard to demonstrate
AI diagnosis capabilities during the hackathon presentation.

> **Note:** Actual image/audio files should be added before the demo.
> The AI classifier works with any crop leaf image.
